这是一篇随项目提供的写作示例，用来展示 Markdown 的基本排版。

## 标题和段落

页面会自动显示笔记标题，正文从二级标题 `##` 开始。段落之间留一行空行。

```markdown
## 一个小主题

第一段，先说明问题。

第二段，记录自己的理解。
```

用 **粗体** 强调少量关键词，用 `行内代码` 标记命令、文件名或变量。

## 列表与引用

- 无序列表适合并列的知识点。
- 有序列表适合按步骤操作的说明。
- 列表不需要太长，能说明白即可。

> 引用适合保留原话。引用他人的内容时，请附上出处链接。

## 链接和图片

```markdown
[显示文字](https://example.com)
![图片说明](/images/my-note.png)
```

将图片放在 `public/images/` 下，引用时使用 `/images/文件名`。图片说明应描述图片包含的信息。

## 代码块

三个反引号后标明语言，就能显示语法高亮：

```javascript
const note = { title: '今天学到的一件事' };
console.log(note.title);
```

代码块可以横向滚动，长命令不会撑开阅读页面。
