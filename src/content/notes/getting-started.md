这是项目自带的入门示例，你可以修改或删除它。这里不需要一开始就有完整的知识体系，先把今天真正想记住的东西写下来。

## 写一篇笔记

在 `src/content/notes/` 下新建一个 Markdown 文件，比如 `my-first-note.md`。文件名就是笔记的网址，建议使用简短的英文和连字符。

在文件顶部填写基本信息：

```yaml
---
title: 我的第一篇笔记
description: 用一句话说清楚，这篇笔记解决什么问题。
date: 2026-11-03
category: 学习记录
tags: [备忘]
draft: false
---
```

接着写正文。标签会自动出现在首页右侧与标签目录中，不需要手动维护导航；分类会显示在阅读页中。

## 给内容一点结构

可以从三个问题开始：

1. 我遇到了什么问题？
2. 我是怎么理解和解决的？
3. 下次遇到时，需要记住什么？

一个段落、一段代码或一张截图，都可以是一篇有用的笔记。不需要为了完整而增加内容。

## 还没写完怎么办

把文件顶部的 `draft` 设为 `true`。草稿不会出现在列表和公开阅读页中。注意：如果 Git 仓库是公开的，草稿源文件仍会被看到。

## 发布到自己的站点

配置好仓库中的 GitHub Actions 后，推送到 `main` 会触发构建。构建产物是一组静态文件，服务器只需要提供静态文件访问。

```bash
git add src/content/notes/
git commit -m "notes: 新增第一篇笔记"
git push origin main
```

服务器配置和部署参数见项目根目录的 `README.md`。首次初始化尚未连接服务器。

> 写给未来的自己，也让偶然路过的人能看懂。
