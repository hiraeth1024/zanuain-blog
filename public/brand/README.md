# Zanuain 最终 Logo · Matrix

基于个人学习笔记站「学习、记录、慢慢积累」和极简几何偏好制作的六个方向。最终选定 02「积点成字 / Matrix」，保留七节点的 Z 形结构，使用 3 个正方形、2 个三角形和 2 个圆形。

用浏览器打开 `index.html`，或启动项目后访问 `/brand/index.html`。页面无需网络依赖，可切换方案、深浅背景及品牌蓝，检查 16–64px 图标并下载原文件。

| 编号 | 方案 | 设计理由 |
| --- | --- | --- |
| 01 | 折页 Z / Fold | 两片错位的折页组成 Z，中间的留白像翻页时的一道光。既保留名字的首字母，也呼应笔记的积累。 |
| 02 | 积点成字 / Matrix | 正方形、三角形与圆形共同排成七节点的 Z。三种几何元素各有轮廓，在统一的网格中构成有节奏的个人标识。 |
| 03 | 思绪成流 / Flow | 六条平行曲线在同一节奏中起伏，像书页、代码流，也像连续书写的思路。强调持续，而非瞬间的灵感。 |
| 04 | 未完一页 / Open | 未闭合的圆角方框是一页未写完的笔记，右上角的圆点表示新的发现。轮廓稳定，开口保留继续探索的空间。 |
| 05 | 字母印记 / Imprint | 实心圆中刻出圆润的 Z，像为每一页笔记落下的个人印章。轮廓集中，适合头像和小尺寸标识。 |
| 06 | 知点相连 / Connect | 一条 Z 形路径连接起点、理解与实践三个节点。以最少的元素表达：知识因联系而变得有用。 |

## 资产

- `svg/`：六款透明底 SVG，统一 `viewBox="0 0 100 100"`，颜色使用 `currentColor`。
- `png/`：六款黑色、透明底 PNG，1024 × 1024。
- `comparison.png`、`comparison.svg`：六款静态对比图。
- `final-preview.png`、`final-preview.svg`：最终方案的正反白预览；原 `recommended-preview.*` 同步为最终方案。
- `logo.svg`：正式矢量文件，使用 currentColor。
- `logo.png`、`logo-white.svg`、`logo-white.png`：1024px 透明黑色版和白色版。
- `logo-192.png`、`logo-512.png`：常用尺寸的透明黑色图标。
- `zanuain-final-logo.zip`：最终版素材包。

SVG 内联到页面时继承 CSS `color`；通过 `<img>` 引用时不能继承外层颜色，需在 SVG 根节点指定 `color`，或使用 CSS mask。PNG 下载保持黑色，页面上的配色切换只影响预览。图文组合中的文字使用系统字体，尚未制作字形轮廓版。建议保持现有留白和纵横比，不拆分、拉伸或重新排列七个几何节点。

网站页头已通过 CSS mask 使用 `/brand/logo.svg`，继承主题颜色；favicon 已改为深底白色 Matrix，同时提供 180px Apple Touch Icon。其余五款保留作探索存档。展示页面借鉴 logo-generator 技能的网格模板，改为无外部依赖的原生 HTML/CSS/JS。

三角形缩小为 16 × 14 单位，上方顶点与方形上沿对齐（y=21），下方顶点与方形下沿对齐（y=79）；圆形保留轻微光学溢出。三角形位于左上和右下，正方形位于右上、中央和左下；上下两组三节点旋转 180° 对应，中央正方形保持稳定，三种轮廓在小尺寸下仍可区分。
